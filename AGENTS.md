# Instruções para agentes

## Plataforma: exclusivamente desktop

Este sistema será usado somente em computadores (PC), conforme decisão do usuário em 14/10/2026.

- Projetar e implementar a interface para navegadores desktop, com mouse e teclado.
- Validar layouts, contraste e usabilidade somente em resoluções de desktop.
- Não gastar tempo ou tokens com versões mobile ou tablet, adaptações específicas, emulação ou capturas desses dispositivos.
- Não remover código responsivo existente apenas para cumprir esta regra; concentre as alterações no trabalho solicitado.
- Esta definição prevalece sobre referências antigas a mobile ou tablet nos documentos e nas skills. Só ampliar o escopo mediante solicitação explícita do usuário.
