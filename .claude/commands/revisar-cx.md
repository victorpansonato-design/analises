Revise $ARGUMENTS (se vazio: o fluxo implementado nesta sessão) com os princípios de `docs/00-visao-geral.md` §3:

1. **Esforço:** conte cliques/campos/trocas de contexto para completar a tarefa principal de cada papel.
   O que dá para remover, pré-preencher ou automatizar?
2. **Próximo passo:** em qualquer estado, a tela diz o que falta, com quem e até quando? Há uma única
   ação primária?
3. **Bloqueios explicados:** toda ação desabilitada diz por quê, em texto visível?
4. **Texto:** pt-BR, sentence case, sem juridiquês, sem vírgula antes do "e" final, erro diz o que fazer.
5. **Promessa = entrega:** algo enviado ao candidato pode mudar depois? (só resumo congelado sai)
6. **Dados:** algum dado sensível aparece sem máscara para quem não precisa?
7. **Medição:** os eventos de domínio/telemetria necessários para os indicadores de `docs/10` estão sendo gerados?

Entregue uma lista priorizada (impacto × esforço) e aplique as correções rápidas.
